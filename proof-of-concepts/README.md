# SSBleed Proof-of-concept

In this directory, we demonstrate the feasibility of SSBleed-v1, SSBleed-v2, and SSBleed-v3 (Section-V).

In `ssbleed-v1-poc`, we demonstrate that the MDP can be exploited to leak control flow across processes. In `ssbleed-v2-poc`, we demonstrate that the MDP can be used to detect interrupts. In `ssbleed-v3-poc`, we demonstrate that the MDP can be updated by transiently executed load instructions.

Please follow the `README.md` file in each subdirectory to build and run the codes.
